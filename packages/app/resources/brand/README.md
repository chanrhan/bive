# BIVE 브랜드 에셋

방향: 클로드 · GPT 계열의 유기적 기하 마크. 글자 없이 세잎 매듭(trefoil) 한 가닥으로, 파랑 명암이 한 바퀴에 밝음→어두움→밝음으로 이음새 없이 흐른다.

| 파일 | 용도 |
|---|---|
| `mark.svg` | 심볼 단독 (216×216 뷰박스, 배경 없음). 파비콘 · 문서 · 배지 원본 |
| `icon.svg` | 앱 아이콘 (256×256, 어두운 둥근 판 위에 심볼) |
| `icon-512.png` | 앱 아이콘 렌더 (512×512, 투명 배경). ICNS · ICO 변환 원본 |
| `logo.svg` · `logo.png` | 가로형 로고, 밝은 배경용 (워드마크 `#0A0A0D`) |
| `logo-dark.svg` · `logo-dark.png` | 가로형 로고, 어두운 배경용 (워드마크 `#F5F5F7`) |
| `logo-stacked.svg` · `logo-stacked.png` | 세로형 로고 (심볼 위, 글자 아래), 밝은 배경용 |
| `logo-stacked-dark.svg` · `logo-stacked-dark.png` | 세로형 로고, 어두운 배경용 |
| `wordmark.svg` · `wordmark-dark.svg` | 글자 단독 (심볼 없음), 밝은 · 어두운 배경용 |
| `mark-figma.svg` | Figma 편집용 심볼. 굵은 스트로크 패스 3개 + 선형 그라데이션만으로 구성해 가져오면 바로 벡터로 수정 가능 |

- 심볼: 토러스 매듭 (2,3). 한 가닥이 세 번 교차하며 세 잎을 만들고, 교차마다 아래 가닥에만 틈을 내어 위아래가 번갈아 엮인다. 풀리지 않는 가장 작은 매듭이라 "확실히 묶여 있다 = 검증됨"을 뜻한다.
- 색: 파랑 명암만 사용. 밝음 `#93C5FD` → 중간 `#3B82F6` → 어두움 `#1D4ED8`. 밝은 쪽이 오른쪽 잎, 어두운 쪽이 왼쪽 아래 잎으로 자연스러운 비대칭이 생긴다. 아이콘 판 `#0E0E11`.
- 작업표시줄 16 · 24 · 32px에서 세 잎 실루엣과 명암 차이가 유지되는 것을 확인했다.
- 워드마크: Inter Display SemiBold, 대문자, 자간 -3.5 (패스 변환본, 폰트 설치 불필요). 색은 밝은 배경 `#0A0A0D`, 어두운 배경 `#F5F5F7`로 중립색만 쓰고 파랑은 심볼에만 쓴다.
- 비율: 가로형은 심볼 높이가 글자 캡 높이의 약 1.5배, 심볼과 글자 간격은 획 두께의 약 1.5배. 세로형은 심볼을 글자 폭에 맞춰 가운데 정렬.
- macOS 26 Icon Composer에는 판과 심볼을 별도 레이어로 넣는다.

## Figma에서 편집하기

- `mark-figma.svg`를 Figma 캔버스에 끌어다 놓으면 `strand-1`~`strand-3` 세 개의 스트로크 벡터와 선형 그라데이션으로 들어온다. 획 두께 22, 둥근 끝 · 둥근 모서리.
- 원본과 같은 한 바퀴 명암 흐름을 원하면 스트로크 색을 Angular 그라데이션(`#93C5FD` → `#3B82F6` → `#1D4ED8` → `#3B82F6` → `#93C5FD`)으로 바꾼다.
- 워드마크를 글자로 편집하려면 Inter Display SemiBold, 자간 -3.8%(92px 기준 -3.5px)로 입력한다. `logo*.svg`의 글자는 패스라 그대로 가져오면 도형으로 들어온다.
- Figma에서 수정한 뒤에는 SVG로 내보내 같은 파일명으로 덮어쓰고 PNG를 다시 렌더한다.
