# BIVE 브랜드 에셋

방향: 신세대 개발 도구(Cursor · Zed · Linear) 계열. 감싸는 도형 없이 글자 하나와 작은 포인트 도형 하나.

| 파일 | 용도 |
|---|---|
| `mark.svg` | 심볼 단독 (B/V 모노그램 + 민트 포인트, 밝은 배경용). 로고 · 문서 · 파비콘 원본 |
| `icon.svg` | 앱 아이콘 (256×256, 운영체제 규격상 어두운 둥근 판 위에 심볼) |
| `icon-512.png` | 앱 아이콘 렌더 (512×512, 투명 배경). ICNS · ICO 변환 원본 |
| `logo.svg` | 가로형 로고 (심볼 + 워드마크, 밝은 배경용). 글자는 패스로 변환되어 폰트 설치 불필요 |
| `logo.png` | 가로형 로고 렌더 (2배 해상도, 투명 배경) |

- 심볼: B의 윗볼은 줄기로 되돌아오는 완전한 볼, 아랫볼은 오른쪽 원호를 돌다 사선으로 꺾여 꼭짓점에서 V가 된다. 안쪽 카운터도 같은 V 꼴이라 B와 V가 한 글자에 겹친다.
- 포인트: 꼭짓점 오른쪽 아래의 작은 민트 사각형 하나. 검증이 끝난 지점을 뜻한다.
- 색: 심볼 `#F5F5F7`(어두운 배경) · `#0A0A0D`(밝은 배경), 포인트 `#2DD4BF`, 아이콘 판 `#0E0E11`.
- macOS 26 Icon Composer에는 판과 심볼을 별도 레이어로 넣는다. 심볼은 단색이라 틴트 변형에 그대로 쓸 수 있다.
- 워드마크 서체: Inter Display SemiBold (패스 변환본).
