# BIVE 브랜드 에셋

방향: 신세대 개발 도구(Cursor · Zed · Warp · Linear) 계열. 단색 기하 심볼 하나, 거의 검은 둥근 판, 광택 없음.

| 파일 | 용도 |
|---|---|
| `icon.svg` | 앱 아이콘 원본 (256×256 뷰박스, 둥근 판 포함) |
| `icon-512.png` | 앱 아이콘 렌더 (512×512, 투명 배경). ICNS · ICO 변환 원본 |
| `logo.svg` | 가로형 로고 (판 없는 심볼 + 워드마크, 밝은 배경용). 글자는 패스로 변환되어 폰트 설치 불필요 |
| `logo.png` | 가로형 로고 렌더 (2배 해상도, 투명 배경) |

- 심볼: V는 Verification이자 BIVE의 글자, 아래 가로 막대는 Baseline. 두 요소뿐이라 16px과 단색 틴트에서도 성립한다.
- 색: 판 `#141418 → #0A0A0D`, 심볼 `#F5F5F7`, 기준선 민트 `#2DD4BF`, 밝은 배경 로고 `#0A0A0D`.
- 어두운 배경용 로고는 `logo.svg`의 `#0A0A0D`를 `#F5F5F7`로 바꾸면 된다.
- macOS 26 Icon Composer용으로는 판 레이어와 심볼 레이어를 분리해 넣는다. 심볼은 단색이므로 틴트 변형에 그대로 쓸 수 있다.
- 워드마크 서체: Inter Display SemiBold (패스 변환본).
