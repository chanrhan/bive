# BIVE 브랜드 에셋

| 파일 | 용도 |
|---|---|
| `icon.svg` | 앱 아이콘 원본 (256×256 뷰박스, 둥근 사각형 배경 포함) |
| `icon-512.png` | 앱 아이콘 렌더 (512×512, 투명 배경). ICNS · ICO 변환 원본 |
| `logo.svg` | 가로형 로고 (아이콘 + 워드마크 + 태그라인). 글자는 패스로 변환되어 폰트 설치 불필요 |
| `logo.png` | 가로형 로고 렌더 (1400×400, 투명 배경, 밝은 배경용) |

- 색: 인디고 그라데이션 `#4F46E5 → #3730A3 → #1E1B4B`, 모노그램 흰색, 검증 체크 민트 `#34D399`, 워드마크 `#0F172A`.
- 의미: B 모노그램 아래 가는 선은 기준선(Baseline), 우하단 체크는 검증(Verification).
- 워드마크 서체: Inter Display Bold · Inter Medium (패스 변환본).
